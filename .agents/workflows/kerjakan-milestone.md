---
description: Mengerjakan satu milestone dari PRD.md
---
1. Baca PRD.md (bagian 5, 6, 7, 10, dan milestone yang diminta).
2. Ringkas kebutuhan milestone dan buat implementation plan.
3. Tunggu persetujuan saya.
4. Implementasikan: migration, model, policy, request, controller, view, test.
5. Jalankan `php artisan test` dan `npm run build`.
6. Cek kriteria "Selesai jika" milestone di PRD, lalu laporkan hasil.
