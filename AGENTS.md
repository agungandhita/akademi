# Aturan Proyek akademipelatihan.com

- Sumber kebenaran: `PRD.md`. Baca penuh sebelum mengubah kode.
- Stack: Laravel 13, Blade, Tailwind (Vite), SweetAlert2, MySQL.
- Kerjakan SATU milestone per sesi, sesuai urutan di PRD bagian 11.
- Buat rencana (file yang diubah) dan tunggu persetujuan sebelum coding.
- Controller tipis. Logika di Action/Service, validasi di Form Request, otorisasi di Policy.
- UI Bahasa Indonesia; kode, tabel, variabel Bahasa Inggris.
- Dilarang: menambah paket di luar stack, membangun fitur Fase 2,
  `migrate:fresh` atau hapus file tanpa konfirmasi.
- Setelah selesai: jalankan `php artisan test` dan `npm run build`, lalu laporkan hasilnya.
